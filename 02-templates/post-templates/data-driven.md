# Template: Post Data-Driven

**Formato:** Análisis de métricas/números/benchmarks
**Plataforma:** LinkedIn (ideal)
**Objetivo:** Credibilidad + Leads B2B
**Longitud:** 150-200 palabras

---

## Estructura:

### 1. Hook (Bold statement con número)
```
[Pregunta provocativa] + [Preview del insight]

Ejemplo:
"¿Qué tan bueno es tu mobile game... realmente? 📊

Estos son los benchmarks de los TOP titles (datos reales de 2025):"
```

### 2. Body (Datos organizados)
```
Formato:
**[Métrica/Categoría]:**
- 🔴 Bad: [Rango bajo]
- 🟡 Good: [Rango medio]
- 🟢 Great: [Rango alto]

O formato comparativo:
**[Categoría A]:**
- [Dato 1]: $XXM
- [Dato 2]: XX%
- [Insight]: [Por qué importa]

**[Categoría B]:**
- [Dato 1]: $XXM
- [Dato 2]: XX%
- [Insight]: [Contraste con A]
```

### 3. Takeaway (Insight accionable)
```
[Regla de oro o recomendación basada en data]

Ejemplo:
"La regla de oro: LTV debe ser 3X tu CAC. Si no... Houston, tenemos un problema."
```

### 4. CTA (Engagement question)
```
[Pregunta que invite a comparar/compartir sus números]

Ejemplo:
"¿Dónde están tus métricas? (Sé honesto 😅)"
"¿Cuál métrica te sorprendió más? 👇"
```

### 5. Hashtags (Industry-focused)
```
#[Industria] #[Métrica] #[Skill] #[Audience] #[Tool]

Ejemplo:
#MobileGaming #Metrics #GameDev #Benchmarking #ProductMetrics
```

---

## Variaciones:

**Comparison Post (A vs B):**
```
Hook: "A vs B: ¿Cuál es mejor? Los números no mienten:"
Body: Side-by-side comparison
Takeaway: "El insight clave: [Winner depende de X]"
```

**Benchmark Post:**
```
Hook: "Estos son los benchmarks de [industria]:"
Body: Ranges (bad/good/great)
Takeaway: "Si estás en 🔴, haz X. Si estás en 🟢, haz Y."
```

**Trend Analysis:**
```
Hook: "Los números de [año] acaban de salir. [Sorpresa]:"
Body: Top performers + insights
Takeaway: "Qué significa esto para ti: [3 bullets]"
```

---

## Tips:

- ✅ Cita fuente de data si es externa
- ✅ Usa emojis para ranges (🔴🟡🟢)
- ✅ Incluye "regla de oro" memorable
- ✅ Contexto personal ("En Amber Studio, vemos esto...")
- ❌ No abrumes con demasiados números
- ❌ Evita data sin interpretación

---

## Credibilidad Boost:

**Añade:**
- "Datos reales de [año]"
- "Trabajando con [clientes/publishers], hemos visto..."
- "Después de analizar [N] juegos..."

**Evita:**
- Claims vagos sin números
- Data outdated sin disclaimer
- Comparaciones unfair (nichos diferentes)

---

**Leverage:** Posts data-driven generan más saves/shares (la gente los usa como referencia)
